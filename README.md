# 📝 Todo App

## 📌 Description
Application web simple permettant de gérer une liste de tâches.

## 🚀 Fonctionnalités
- Ajouter une tâche
- Supprimer une tâche
- Marquer comme terminée
- Filtrer les tâches
- Sauvegarde avec localStorage

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## 📂 Installation
1. Cloner le projet
2. Ouvrir index.html

## 🌍 Déploiement
Déployé avec GitHub Pages
